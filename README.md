# Amazon-Product-Demand-Forecasting-using-Machine-Learning

## Problem Statement

The objective of this project is to analyze historical Amazon sales data
and build a Machine Learning model to predict product demand.
The project helps understand sales patterns and the factors affecting
product demand.

## Project Description

This project analyzes Amazon sales data using Machine Learning.
The dataset contains information such as product category, price,
discount percentage, quantity sold, customer region, ratings,
review count, discounted price, and total revenue.

The project includes data cleaning, data preprocessing, Exploratory
Data Analysis (EDA), feature engineering, model training, and model
evaluation.

## Conclusion

The project demonstrates how Machine Learning can be used to analyze
Amazon sales data, identify important sales patterns, and predict
product demand for better inventory and sales planning.
